# Druckliste: Familien-Dokumentenarchiv

Stand: 2026-07-20

Ziel: Paperless und physische Ordner haben dieselbe Logik. Wenn ein Dokument in
Paperless geöffnet wird, muss sofort klar sein, wo das Papieroriginal liegt.

## 1. Grundprinzip

```text
Person         = Wem gehört das Dokument?
Ordner         = In welchen Lebensbereich gehört es?
Dokumenttyp    = Was ist es?
Physischer Ort = Wo liegt das Papieroriginal?
```

Strikte Paperless-Regel:

```text
Jedes Dokument hat genau einen person-* Tag.
Jedes Dokument hat genau einen ordner-* Tag.
Jedes Dokument hat genau einen Dokumenttyp.
Jedes behaltene Original hat einen physischen Ort.
```

## 2. Physische Ordner-Namensregel

Alle physischen Ordner werden so beschriftet:

```text
<Person>-<Ordnernummer>-<Lebensbereich>
```

Beispiele:

```text
Vahab-03-Arbeit-und-Einkommen
Partnerin-06-Gesundheit
Kind-01-Person-und-Identität
Familie-07-Wohnen-und-Verträge
```

Nur Ordner anlegen, die wirklich gebraucht werden. Nicht für jede Person alle
Kategorien leer vorbereiten.

## 3. Personen-Gruppen

```text
Vahab
Partnerin
Kind
Familie
```

`Familie` ist für gemeinsame Dokumente: Mietvertrag, Wohnung, gemeinsame
Versicherungen, gemeinsame Verträge, Familienunterlagen.

Wichtig:

```text
Mobilität ist normalerweise personenspezifisch.
Behörden-und-Recht ist normalerweise personenspezifisch.
```

Nur gemeinsame Fälle kommen in `Familie`, zum Beispiel ein gemeinsamer
Mietvertrag, eine gemeinsame Haushaltsversicherung oder ein Schreiben, das
wirklich den ganzen Haushalt betrifft.

Person ablegen.

## 6. Was gehört wohin?

| Ordner | Inhalt |
| --- | --- |
| 01-Person-und-Identität | Ausweis-Kopien, Aufenthaltstitel, Geburtsurkunde, Heiratsurkunde, Namensänderung |
| 02-Ausbildung-und-Beruf | Bachelorzeugnis, Masterzeugnis, Transcript of Records, Arbeitszeugnisse, Zertifikate, Fortbildungen |
| 03-Arbeit-und-Einkommen | Arbeitsvertrag, Lohnabrechnungen, Gehaltsabrechnungen, Arbeitgeberbriefe, Bescheinigungen |
| 04-Finanzen-und-Steuern | Steuerbescheide, Steuererklärungen, Kontoauszüge, Bankunterlagen, Kreditunterlagen, Rechnungen |
| 05-Versicherung-und-Vorsorge | Renteninformation, Rentenversicherung, Berufsunfähigkeit, Haftpflicht, Hausrat, Kfz, Krankenversicherungspolicen |
| 06-Gesundheit | Arztbriefe, Befunde, Impfungen, Rezepte, Krankenhaus, Krankenkasse, Zahnarzt |
| 07-Wohnen-und-Verträge | Mietvertrag, Nebenkosten, Strom, Gas, Internet, Handy, Kaufverträge, Garantieunterlagen |
| 08-Behörden-und-Recht | Finanzamt, Ausländerbehörde, Jobcenter, Gericht, Polizei, Bescheide, Widersprüche |
| 09-Mobilität | Führerschein, Fahrzeugbrief, Fahrzeugschein, TÜV, Werkstatt, Bahn, Deutschlandticket |
| 10-Familie | Partner, Kind, Eltern, Vollmachten, Erbe, Pflege, wichtige Familienunterlagen |
| 90-Archiv | Alte, selten gebrauchte, abgeschlossene Unterlagen |

## 7. Trennblätter in jedem Ordner

In jedem Ordner dieselben Trennblätter verwenden:

```text
A - Aktuell
B - Wichtig dauerhaft
C - Abgeschlossen
D - Alt
```

## 8. Bewegungsregeln für Trennblätter

Die Trennblätter sind nicht statisch. Einige Dokumente wandern mit der Zeit.

```text
A - Aktuell
```

Für aktive, laufende oder noch nicht abgeschlossene Themen.

Nach `C - Abgeschlossen` verschieben, wenn das Thema erledigt ist:

```text
laufender Versicherungsfall -> abgeschlossen
aktuelles Steuerjahr -> Steuerbescheid erhalten
aktuelle Bewerbung / Arbeitssache -> erledigt
aktuelle Behandlung -> abgeschlossen
```

```text
B - Wichtig dauerhaft
```

Für wichtige Originale, die langfristig schnell auffindbar bleiben sollen.
Diese Dokumente normalerweise nicht verschieben.

Beispiele:

```text
Geburtsurkunde
Zeugnisse
wichtige Verträge
Versicherungspolicen
wichtige medizinische Unterlagen
Renteninformation
```

```text
C - Abgeschlossen
```

Für erledigte, aber noch relevante Unterlagen.

Nach `D - Alt` verschieben, wenn sie alt sind und selten gebraucht werden:

```text
alte Rechnungen
alte abgeschlossene Verträge
alte Wohnungsunterlagen
alte Korrespondenz
```

```text
D - Alt
```

Für alte Unterlagen, die selten gebraucht werden, aber noch nicht entsorgt
werden sollen.

Empfohlener Rhythmus:

```text
Einmal pro Jahr prüfen, z.B. im Januar.
```

Jahresprüfung:

```text
A -> C, wenn abgeschlossen
C -> D, wenn alt und selten gebraucht
D -> 90-Archiv oder entsorgen, wenn sicher nicht mehr nötig
B bleibt meistens unverändert
```

Wenn ein Papierdokument verschoben wird, in Paperless nur den physischen Ort
anpassen:

```text
Vahab / O03 / A / 2026
```

wird zum Beispiel:

```text
Vahab / O03 / C / 2026
```

## 9. Paperless Personen-Tags

Die Tags bleiben bewusst ASCII und kleingeschrieben, damit sie stabil,
suchfreundlich und einfach zu tippen sind.

```text
person-ich
person-partnerin
person-kind
person-familie
```

Regel: Genau ein Personen-Tag pro Dokument.

## 10. Paperless Ordner-Tags

Die Tags bleiben bewusst ASCII und kleingeschrieben.

```text
ordner-01-person-identitaet
ordner-02-ausbildung-beruf
```

Regel: Genau ein Ordner-Tag pro Dokument.

## 12. Physischer Ort in Paperless

Für jedes behaltene Original den physischen Ort notieren:

```text
<Person> / O<Ordnernummer> / <Trennblatt> / <Jahr oder dauerhaft>
```

Beispiele:

```text
Vahab / O03 / A / 2026
Partnerin / O06 / B / 2026
Kind / O01 / B / dauerhaft
Familie / O07 / B / dauerhaft
```

Wenn kein Original behalten wird:

```text
Physischer Ort: kein Original
Original behalten: Nein
```

## 13. Titelregel in Paperless

```text
YYYY-MM-DD - Absender - Dokumenttyp - Betreff
```

Beispiele:

```text
2026-07-20 - Arbeitgeber - Lohnabrechnung - Juli
2026-06-10 - TK - Arztbrief - Kontrolluntersuchung
2025-11-12 - Finanzamt - Steuerbescheid - 2024
2024-09-01 - Universität - Zeugnis - Masterabschluss
```

## 14. Minimale Metadaten pro Dokument

| Feld | Strikte Regel |
| --- | --- |
| Titel | Nach Titelregel schreiben |
| Datum | echtes Dokumentdatum, nicht Scan-Datum |
| Korrespondent | Absender, z.B. Finanzamt, Arbeitgeber, Krankenkasse |
| Personen-Tag | genau einer, z.B. `person-ich` |
| Ordner-Tag | genau einer, z.B. `ordner-06-gesundheit` |
| Dokumenttyp | genau einer, z.B. `Arztbrief` |
| Physischer Ort | falls Original bleibt, z.B. `Vahab / O06 / B / 2026` |
| Original behalten | Ja / Nein / Unsicher |

## 15. Entscheidungsregel: Person oder Familie?

```text
Wenn das Dokument hauptsächlich eine Person betrifft:
-> person-ich / person-partnerin / person-kind

Wenn das Dokument den Haushalt oder mehrere Personen betrifft:
-> person-familie
```

Beispiele:

```text
Gehaltsabrechnung von Vahab
-> person-ich
-> ordner-03-arbeit-einkommen
-> Physischer Ort: Vahab / O03 / A / 2026

Arztbrief der Partnerin
-> person-partnerin
-> ordner-06-gesundheit
-> Physischer Ort: Partnerin / O06 / B / 2026

Geburtsurkunde Kind
-> person-kind
-> ordner-01-person-identitaet
-> Physischer Ort: Kind / O01 / B / dauerhaft

Mietvertrag der Wohnung
-> person-familie
-> ordner-07-wohnen-vertraege
-> Physischer Ort: Familie / O07 / B / dauerhaft

Führerschein Partnerin
-> person-partnerin
-> ordner-09-mobilitaet
-> Physischer Ort: Partnerin / O09 / B / dauerhaft

Bescheid für Vahab
-> person-ich
-> ordner-08-behoerden-recht
-> Physischer Ort: Vahab / O08 / A / 2026
```

## 16. Scan-Workflow

```text
1. Scannen:
   scan-to-paperless

2. In Paperless kontrollieren:
   Datum, Korrespondent, Dokumenttyp

3. Tags setzen:
   genau ein person-* Tag
   genau ein ordner-* Tag

4. Original entscheiden:
   behalten / entsorgen / unsicher

5. Wenn behalten:
   in passenden physischen Ordner legen
   Trennblatt wählen
   physischen Ort in Paperless eintragen
```

## 17. Kurzregel

```text
Person sagt: Wem gehört es?
Ordner sagt: In welchen Lebensbereich gehört es?
Dokumenttyp sagt: Was ist es?
Physischer Ort sagt: Wo liegt das Papier?
Paperless sagt: Wie finde ich es wieder?
```
